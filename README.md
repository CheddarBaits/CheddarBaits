# CheddarBaits Website

This is the first GitHub Pages-ready version of the CheddarBaits website.

## Files

- `index.html` — main website
- `style.css` — appearance/layout
- `script.js` — mobile menu and year
- `assets/` — logos and banner

## Add product photos later

Put your product images inside `assets/`, then replace a product's placeholder in `index.html` with an image such as:

`<img src="assets/my-lure.jpg" alt="My lure">`

## Change the contact email

Search `index.html` for:

`YOUR-EMAIL-HERE`

and replace it with your real email address.

## Put it online for free

1. Create a GitHub account if you don't already have one.
2. Create a new public repository named `cheddarbaits`.
3. Upload all files and the `assets` folder.
4. Go to the repository's **Settings → Pages**.
5. Set the source to **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.

GitHub will give you a free `github.io` website address.

When you eventually buy your own domain, GitHub Pages can use that same website with the custom domain.
